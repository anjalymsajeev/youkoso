# Security policy

## Supported versions

youkoso has not been released yet. Once releases begin, security fixes will target the latest
released version.

## Reporting a vulnerability

Please **do not** report security vulnerabilities in public issues, discussions or pull requests.

Report them privately through GitHub:
[Report a vulnerability](https://github.com/anjalymsajeev/youkoso/security/advisories/new).

Include a description of the issue, the affected versions and steps to reproduce. You can expect
an acknowledgement within 7 days. Once a fix is available, the advisory will be published and you
will be credited unless you prefer otherwise.
